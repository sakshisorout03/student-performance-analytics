# Student Performance Analytics System

**Internship Project - EWB Courses**
**Student:** Sakshi - MKM College of Management and IT for Girls, Hodal (Palwal)
**Course:** Python with AI & Data Science

### 1. Project Objective
The objective of this project is to analyze student performance based on marks and attendance. It calculates total marks, average, grades and identifies top performers.

### 2. Technologies Used
- Python 3.8
- NumPy - For numerical calculations
- Pandas - For data reading and analysis
- VS Code

### 3. Dataset Information
File: `students.csv` (20 Records)
Columns: 
- Student_ID (1001-1020)
- Name
- Department (BCA, MCA, BBA, MBA)
- Python, AI_ML, Data_Science (Marks)
- Attendance (%)
